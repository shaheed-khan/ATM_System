# 🏧 Python ATM System

A simple ATM system built using Python.  
This project demonstrates basic file handling, modular programming, and user authentication.

## 🚀 Features

- 🔐 User Authentication (Account Number + PIN)
- 💰 Check Balance
- ➕ Deposit Money
- ➖ Withdraw Money
- 📂 File-based data storage using JSON
- 🧩 Modular structure (separate logic files)

- JSON (for data storage)
- File Handling
- Functions & Modules
